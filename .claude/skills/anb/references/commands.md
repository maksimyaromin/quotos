### Global options

| Flag | Meaning |
|---|---|
| `--json` | JSON instead of TOON, with the same fields and selected content |
| `--notebook <PATH>` | Use this notebook path instead of the nearest .agent-notebook. Overrides `ANB_NOTEBOOK`; relative paths start at the working directory |
| `--global` | Your private knowledge across projects, in the home directory. Holds Notes and Decisions. Cannot combine with --notebook or --personal |
| `--personal` | Your private knowledge for this project, outside the repository. Recall includes it automatically alongside shared project knowledge |
| `--session <ID>` | Local agent session; `ANB_SESSION` or `CODEX_THREAD_ID` supplies the default |

### Narrowing

A read answers with the records its narrowing admits. Each flag is a predicate over the same notebook, so two flags ask for the intersection, and a flag means the same on every verb that takes it; a verb's section names its own. Without `--by`, `--mine` or `--team`, the notebook's `scope` config key decides whose records a read answers with.

| Flag | Meaning |
|---|---|
| `--by <NAME>` | Only this identity's work: the tasks it holds, the records it wrote and the records waiting on it |
| `--mine` | Only your own: `--by` with the identity the writers sign with |
| `--team` | Everyone's, whatever the notebook's `scope` key says |
| `--untaken` | Only the tasks nobody holds, the pool anyone may take, whatever the notebook's `scope` key says |
| `--to <NAME>` | Only the records addressed to this person |
| `--for <ID>` | Only this subject and records created from it, following origins through every descendant. Dependencies still govern readiness |
| `--tag <TAG>` | Only records carrying this tag; repeated, carrying every one |
| `--match <TEXT>` | Match text in record ids, titles, tags, people or bodies, ignoring case |
| `--type <TYPE>` | Select record types, comma-separated or repeated. By default, include every type and records whose type could not be parsed |
| `--kind <KIND>` | Only records of these kinds, comma-separated or repeated: a Decision's rule, shape or drift; a Note's fact, term, guide, idea, model or spec |
| `--archive` | The archive too; by default only the work still in play |

### anb recall

Recall your work, shared knowledge and personal practices. Search by a phrase, or name a record with --for to prioritize its context

Arguments: `[TEXT]`

| Flag | Meaning |
|---|---|
| `--for <ID>` | Prioritize knowledge related to this project record |
| `--all` | Include every matching record and its full body |

Narrowing: `--by`, `--mine`, `--team`.

### anb add

Create a record: `add task|decision|note|question "<title>"`. The notebook appears on first write

Arguments: `<RECORD_TYPE> <TITLE>`

| Flag | Meaning |
|---|---|
| `--id <ID>` | Choose a stable id. By default the CLI allocates a random 128-bit id |
| `--from <FROM>` | Origin: the record this record was born from |
| `--tag <TAG>` | A tag; repeatable |
| `--link <LINK>` | `<kind> <target>`, e.g. `pr https://…`; repeatable |
| `--body <BODY>` | Record body text; omitted, the body starts empty |
| `--body-file <PATH>` | Read the body from a file; `-` reads standard input. Cannot combine with --body |
| `--by <BY>` | The accountable identity; omitted, `ANB_BY` or the git identity fills it |
| `--via <VIA>` | The acting agent tool |
| `--taken-by <NAME>` | Assign the Task to this person. If omitted, leave it unassigned until someone starts it |
| `--mine` | Assign the Task to yourself, using the current identity |
| `--to <NAME>` | Whom the record waits on: the person a question is put to, or the one a task's review will be handed to. Omitted, it waits on nobody in particular |
| `--priority <PRIORITY>` | A task's urgency, 0 to 4, 0 the most urgent |
| `--kind <KIND>` | A decision's rule, shape, or drift; a note's fact, term, guide, idea, model, or spec |
| `--supersedes <SUPERSEDES>` | The Decision or Note this record replaces; marks its predecessor superseded in the same operation |

### anb start

Start or resume a Task. Records your assignment and refuses work held by someone else

Arguments: `[ID]`

| Flag | Meaning |
|---|---|
| `--next` | Start the next ready Task: your assigned work first, then unclaimed work |
| `--for <ID>` | Restrict --next to this record's scope |

### anb close

Close completed work with an outcome. Use --reason to cancel a Task or settle a Question, or --resolved-by to cite its answer

Arguments: `<ID>`

| Flag | Meaning |
|---|---|
| `--body <BODY>` | Record the completed Task's outcome in its body |
| `--body-file <PATH>` | Read the outcome from a file; `-` reads standard input |
| `--via <VIA>` | The acting agent tool recording the outcome |
| `--reason <WHY>` | Cancel a Task or settle a Question with an explanation recorded in its header |
| `--resolved-by <ID>` | The Decision or Task that settled the Question |

### anb edit

Change a record's wording, assignment, tags or links. Use lifecycle commands for state

Arguments: `<ID>`

| Flag | Meaning |
|---|---|
| `--title <TITLE>` | The whole title, replaced |
| `--body <BODY>` | The whole body, replaced; empty clears it |
| `--body-file <PATH>` | Replace the body with a file's text; `-` reads standard input. Cannot combine with --body |
| `--tag <TAG>` | Add a tag; repeatable |
| `--untag <TAG>` | Remove a tag; repeatable |
| `--link <LINK>` | Add a link, `<kind> <target>`; repeatable. Use a record id for a shared relationship or a URL for an external source |
| `--unlink <LINK>` | Remove a link, spelled as it stands; repeatable |
| `--from <FROM>` | Origin: the record this record was born from |
| `--priority <PRIORITY>` | 0 to 4, 0 the most urgent |
| `--review-by <DATE>` | The explicit resurfacing date |
| `--taken-by <NAME>` | Assign the Task to this person, allowing them to start it |
| `--to <NAME>` | Whom the task or question waits on |
| `--clear <FIELD>` | The optional field to erase: `from`, `priority`, `review-by`, `taken-by`, or `to`; repeatable |

### anb graph

Read the relationship graph for a notebook or a selected group of records

| Flag | Meaning |
|---|---|
| `--focus <ID>` | Only this record and the graph around it |
| `--depth <N>` | How many edges out from `--focus` the graph reaches; 1 by default |
| `--full` | Each record's envelope and body as well |
| `--all` | Include complete record fields and bodies. Both formats always include every graph edge |

Narrowing: `--by`, `--mine`, `--team`, `--untaken`, `--to`, `--for`, `--tag`, `--match`, `--type`, `--kind`, `--archive`.

| `--remove` | Remove managed integration files for the named agents |
